01 / About

Quest Planner is a lightweight, distraction-free task management application built to solve my own developer study friction. It frames programming goals and daily assignments as RPG quests with experience points (XP), priority badges, and streak counters.

02 / The Problem

Traditional to-do apps can feel clinical and repetitive. When tackling daunting multi-week programming topics (such as learning data structures or building fullstack architectures), lack of immediate feedback leads to procrastination.

03 / The Solution

  • Tiered Quest Sizing: Break large goals into Easy (10 XP), Medium (25 XP), and Boss Fight (100 XP) milestones.
  • Instant State Persistence: Zero signup friction—uses robust browser LocalStorage data serialization with JSON export/import.
  • Developer Streak Tracker: Visual day-by-day contribution blocks similar to GitHub's commit graph.
  • Keyboard Accessibility: Quick-add tasks with Ctrl + Enter and filter with hotkeys.

04 / My Role

As the Lead Developer, I designed the interface, wrote modular object-oriented JavaScript, handled state persistence, and crafted clean CSS micro-animations.

06 / Challenges

1. Preventing UI Desynchronization with Fast User Clicks

Early versions triggered duplicate XP awards if buttons were rapidly double-clicked. Implemented a single centralized state store where state updates trigger render cycles deterministically.

07 / What I Learned

This project gave me rock-solid confidence in raw JavaScript fundamentals, manipulating the DOM without external libraries, and structuring clean, event-driven client applications.
