QCU MERCHMART & ADMIN

Integrated e-commerce cooperative marketplace and real-time administrative back-office system for university merchandise, uniforms, books, and student pre-orders.

Timeline 2024 · 2nd/3rd Year BSIT
Category Academic / Web System
My Role Lead Developer
Primary Stack PHP · MySQL · JavaScript · CSS3

01 / About

QCU MerchMart is an academic e-commerce web platform created for Quezon City University's cooperative store. It enables students and faculty to browse university merchandise, pre-order uniforms and school supplies, track order fulfillment statuses, and manage inventory via a dedicated administrative dashboard.

02 / The Problem

At the start of every academic semester, the physical campus cooperative experiences massive queues and stock discrepancies:

  • Manual order handling: Long physical waitlines for size inquiries and item availability checks.
  • Inventory blindspots: Cashiers lacked automated low-stock warnings, leading to unfulfilled orders.
  • Paper receipts: Difficulty tracking revenue summaries and order settlement records.

03 / The Solution

We built a two-sided web portal:

  • Student Storefront: Interactive product catalog with category filters, shopping cart, checkout workflow, and order receipt printing.
  • Admin Back-Office: Comprehensive control panel for stock adjustment, order status updates (Pending, Processing, Claimed, Cancelled), sales analytics, and user role management.
  • Relational MySQL Schema: ACID-compliant transactions to prevent inventory overselling during simultaneous checkouts.

04 / My Role

As the Lead Developer:

  • Developed the administrative control center including table sorting, search filters, and modal-based CRUD operations.
  • Constructed PHP session management, password hashing (bcrypt), and secure database querying using prepared PDO statements.
  • Designed the relational database tables for users, products, categories, orders, and order items.
  • Integrated client-side cart logic in vanilla JavaScript for instant price recalculations.
