01 / About

Zentaku is a highly polished, dark-mode-first anime and manga tracking platform that bridges the gap between discovering new manga and streaming your favorite anime — all in one place.

Built entirely without reliance on third-party public proxy APIs, Zentaku uses a native scraping architecture to provide fast, accurate data while avoiding DMCA takedowns.

02 / The Problem

Anime and manga fans often bounce between multiple fragmented platforms — one for tracking, one for streaming, another for reading. Most aggregator sites:

  • Rely on unstable public proxies: Many sites break frequently or go down due to DMCA enforcement on shared proxy configurations.
  • Have poor UI/UX: Crowded with ads, slow load times, and no cohesive design language.
  • No unified experience: Separate services for anime tracking, streaming, and manga reading with no cross-linking.

03 / The Solution

Zentaku provides a unified, premium-grade platform:

  • Anime Streaming: Powered securely via @consumet/extensions (AnimeKai provider), utilizing a completely self-sufficient backend API route system — no .env proxy configurations required.
  • Manga Vault: Comprehensive manga tracking and chapter parsing utilizing the Jikan (MyAnimeList) API and MangaDex.
  • Premium UI: Glassmorphism components, smooth micro-animations, pitch-black base with deep red accents, and fully adaptive layouts from mobile to ultra-wide.
  • Lightning Fast Rendering: Leverages Next.js 15 App Router, caching, and Server Components for fast page loads.

04 / My Role

As the Lead Developer, I was responsible for:

  • Architecting the Next.js App Router structure and self-sufficient backend API routes.
  • Integrating @consumet/extensions for anime streaming without relying on public proxies.
  • Implementing Jikan API and MangaDex integration for the Manga Vault module.
  • Designing the entire UI system — glassmorphism components, dark-mode tokens, and adaptive layouts.
  • Deploying the platform to Vercel with production-level caching strategies.

06 / Challenges

1. DMCA-Safe Streaming Architecture

Building a compliant streaming solution required using a self-sufficient backend API route system via @consumet/extensions instead of public proxies, ensuring the platform avoids third-party DMCA exposure.

2. Adaptive Layout Across Devices

Designed layouts that scroll horizontally on tablets, stack intelligently on mobile, and utilize powerful CSS grid rules on ultra-wide monitors — all without sacrificing the premium aesthetic.

07 / What I Learned

Zentaku pushed me deeper into Next.js 15's App Router, Server Components, and caching strategies. It also taught me how to design a premium-feel dark UI from scratch using Tailwind — and how to think about legal compliance in API-driven media platforms.
