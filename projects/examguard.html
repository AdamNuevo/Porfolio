01 / About

ExamGuard is a dedicated mobile examination proctoring application developed to address academic integrity during remote and hybrid testing. It turns student smartphones into secure testing environments that prevent multitasking, background app switching, and unauthorized assistance.

02 / The Problem

When students take exams on personal mobile devices, maintaining fair testing conditions is notoriously difficult:

  • Seamless app switching: Students can quickly jump between exam screens, messaging apps, and web browsers.
  • Screen recording & split screen: Mobile OS features allow background screen capturing or concurrent app windows.
  • Proctor visibility: Instructors lack real-time signals when a mobile student navigates away from the active assessment.

03 / The Solution

ExamGuard provides a mobile-locked testing environment:

  • App Lifecycle & Focus Tracking: Detects whenever the application is paused, backgrounded, or split-screened, logging precise timestamps.
  • Front Camera Stream: Periodic low-bandwidth WebRTC video frames for student presence and identity verification.
  • Instant Proctor Alerts: Real-time socket events notify the instructor dashboard the second an anomaly or app switch occurs.
  • Sandboxed Test Engine: Clean, distraction-free mobile question runner with offline answer queuing.

06 / Challenges

1. Minimizing False Positives from System Notifications

OS popups (e.g. anti-virus alerts or low-battery prompts) could inadvertently fire blur events. I implemented a grace debounce period and threshold-based scoring rather than immediate penalization.

2. Maintaining Low Latency WebSocket Connections Across Multiple Concurrent Test Takers

Batched telemetry heartbeat packets every 3 seconds to reduce socket congestion on the Express server while preserving high-precision event logs.
